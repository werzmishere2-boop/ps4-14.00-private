# Ourfit — Fashion Clothing Store HTML Template (FREE)

Ourfit is a modern, elegant **Bootstrap 5** HTML template built for fashion & clothing e-commerce stores.

This is the **FREE, homepage-only** preview of the template. It contains a single page — `index.html` — built with the full design system, real photography, and working interactive components (product filters, testimonial switcher, mobile navigation, newsletter form) so you can evaluate the look, feel, and code quality before upgrading.

**Want the full multipage version?** The **PRO** edition adds a Shop grid, Product Details, Cart, Checkout, Wishlist, About, Blog, Blog Details, a functional Contact page, and a 404 page — get it at **[templatesjungle.com](https://templatesjungle.com)**.

## Folder Structure

```
free/
├── index.html
└── assets/
    ├── css/style.css
    ├── js/script.js
    ├── images/                  (subset of images used on the homepage only)
    └── vendor/
        ├── bootstrap/            (Bootstrap 5.3 CSS + JS, self-hosted)
        └── bootstrap-icons/      (Bootstrap Icons, self-hosted)
```

Bootstrap and Bootstrap Icons are bundled locally under `assets/vendor/` — this page works fully offline, no CDN required. Fonts (**Jost** for headings, **Poppins** for body) are loaded from Google Fonts.

---

## Getting Started

Just open `index.html` in your browser — or serve the folder locally:

```bash
npx serve free
```

---

## Customizing

- **Colors, type, spacing** — design tokens live at the top of `assets/css/style.css` under `:root`.
- **Images** — replace files in `assets/images/`.
- **Icons** — [Bootstrap Icons](https://icons.getbootstrap.com/), already bundled.
